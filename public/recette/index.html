Du frigo à l'assiette : ce que mijote vraiment votre bundler JavaScript

Pour 1 application 7 étapes

Ingrédients

Préparation

  1. Ouvrir le frigo

    sources
    • Le navigateur ne lit que du HTML, du CSS et du JavaScript. Le bundler traduit tout le reste.

  2. Faire la liste de courses

    graphe de dépendances
    • Le bundler part d'un seul fichier et suit chaque import pour trouver les autres.
    • Il retient ce qu'il a déjà visité. Un import circulaire ne tourne pas en boucle, un fichier partagé n'entre qu'une fois.

  3. Préparer chaque ingrédient

    transpilation et modules
    • Un loader ou un plugin transforme chaque type de fichier en JavaScript ou en CSS.
    • Un import ESM se résout au build. Un require() CommonJS se résout à l'exécution et ajoute du code au bundle.
    • Préférez les dépendances publiées en ESM.

  4. Le tri

    tree‑shaking
    • Le bundler retire tout ce que le graphe n'atteint pas. Il n'y arrive qu'avec de l'ESM.
    • Importer debounce depuis lodash embarque 72 KB. Depuis lodash-es, 2,8 KB.
    • Les barrel files, un sideEffects mal posé et le CommonJS bloquent le tri.

  5. Le découpage

    code splitting
    • Chaque import() crée un fichier à part, chargé au moment où on en a besoin.
    • Le code commun à plusieurs pages part dans un fichier partagé, mis en cache une seule fois.

  6. La réduction

    minification
    • Le minifieur réécrit le code en plus court, renomme les variables locales et supprime espaces et commentaires.
    • La taille finale change peu d'un minifieur à l'autre. On le choisit pour sa vitesse.

  7. Le service

    dev et prod
    • En dev, Vite sert vos fichiers un par un, sans bundle. En prod, il bundle.
    • Les source maps relient le code minifié à vos sources. En prod, gardez la .map hors de portée du public.

Les bundlers du moment

  • ViteJavaScript

    Sert vos modules tels quels en dev, bundle avec Rolldown en prod.

  • RolldownRust

    Compatible avec Rollup, c'est le moteur de Vite 8.

  • esbuildGo

    Rapide et minimaliste, souvent utilisé comme brique par d'autres outils.

  • RspackRust

    Reprend la config de webpack et va beaucoup plus vite.

La note du chef

  1. 1Pas de magie. Un bundler enchaîne des transformations, chacune avec un rôle précis.
  2. 2Bundle = perf. Ce que le bundler produit, c'est ce que vos utilisateurs téléchargent.
  3. 3Choisir = compromis. Aucun bundler ne gagne partout. Vous arbitrez entre config, vitesse et écosystème.
